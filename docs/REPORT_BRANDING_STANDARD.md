## 1. Executive Branding Directives

All human-readable reports, PDF exports, printable HTML pages, CER grids, Excel workbooks, and executive summaries generated by IDS Pulse must strictly adhere to the following branding and data integrity standards:

1. **One Canonical Logo**: All reports must render the official Integrity Driven Solutions Inc. logo sourced exclusively from `src/config/brandingConfig.js` (`LOGO_BASE64` from `LogoBase64.js`).
2. **First-Page Header**: The full approved logo must appear in the top-left header of the first page (minimum width 46mm, preserving original aspect ratio).
3. **Continuation Pages**: Subsequent pages must display a branded header line and confidential footer notice.
4. **Readability Minimums**:
   - Section Headings: Minimum 12 pt bold (`#031D37`)
   - Table Headers: Minimum 9.5–10 pt bold (`#031D37` background, `#FFFFFF` text)
   - Table Body Data: Minimum 9 pt
   - Normal Body Text: Minimum 10 pt
5. **Orientation Rules**:
   - Use **Portrait** for single-item form reports with 6 or fewer columns.
   - Use **Landscape** (US Letter Landscape) for wide tables, operational feeds, financial CER grids, rework logs, timesheet histories, and any report containing 7 or more columns.
6. **Zero Text Truncation**: Ellipsis (`...`) or CSS-style clipping is strictly prohibited for report data. Complete narratives, notes, and action items must wrap onto multi-line rows using dynamic row height (`overflow: 'linebreak'`).
7. **Machine File Exception**: QuickBooks CSV, IIF, and JSON import files must remain clean machine data (no embedded Base64 image strings).

## 3. Shared Report Shell Architecture

All PDF, Excel, and HTML print generators must invoke the unified report shell in `src/utils/sharedReportShell.js`. The shell automatically manages:
- Logo placement and scaling;
- Header confidentiality badges;
- Running page numbers (`Page X of Y`);
- Dynamic timestamping and actor audit trail (`Generated by [User] on [Timestamp]`);
- Repeat table headers (`showHead: 'everyPage'`);
- Page break avoidance for single rows (`rowPageBreak: 'avoid'`).
